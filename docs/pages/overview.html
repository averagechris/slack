slack-rs overview

A hardened Slack Web API CLI

slack-rs is a Rust command-line client for the Slack Web API, built for OAuth profiles, JSON output, and safe automation around messages, conversations, users, search, threads, reactions, and files.

Install / downloadSee an exampleSource repository

At a glance

Slack API access

slack api call can call any Slack Web API method with key=value parameters, JSON bodies, GET requests, raw responses, and bot or user token selection.

Convenience wrappers

First-class commands cover message posting/updating/deleting, conversation listing/history/search/open, message search, user info and lookups, threads, reactions, and file upload/download.

Profiles and OAuth

OAuth PKCE login stores independent workspace profiles. Cloudflare Tunnel can provide the redirect URI, and profile metadata stays separate from secrets.

Agent-friendly output

Commands default to a JSON envelope with response and meta; --raw returns Slack-native response shapes when scripts need them.

Credential hardening

Tokens and OAuth client secrets live in the OS keyring, not plaintext token files or SLACK_TOKEN. Legacy token migration deletes the old file after import.

Local validation

This fork is Nix-native with no hosted PR CI. Builds, tests, release tarballs, and pages are driven locally by flake apps.

Main workflows

01 Authenticate a workspace

Log in once per profile, optionally using cloudflared for the OAuth callback.

slack auth login team-eng --cloudflared
slack auth status team-eng

02 Read and search Slack

List conversations, fetch history, search messages, and resolve user information with structured results.

slack conv list --filter name:team-* --limit 20
slack search "deploy notes" --count 5
slack users info U123456

03 Write deliberately

Wrapper commands for posts, updates, deletes, reactions, and uploads honor the write guard environment variable.

SLACKCLI_ALLOW_WRITE=true slack msg post C123456 "Deploy window starts at 15:00 UTC"
SLACKCLI_ALLOW_WRITE=false slack react add C123456 1720000000.000100 eyes
