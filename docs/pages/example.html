slack-rs example

Post an update, then find it later

This sanitized transcript shows a realistic workflow: select a channel, post a short status message, and search for it. IDs, names, text, and timestamps are representative only.

Install / downloadOverview

No real Slack API was called to produce this example. The commands and flags match the CLI surface; the JSON shows the default envelope shape with response and meta.

1. List candidate channels

Conversation wrappers call Slack's conversations API. Here, --filter name:team-* narrows results and --limit keeps the output small.

$ slack --profile team-eng conv list --filter name:team-* --limit 2
{
  "response": {
    "ok": true,
    "channels": [
      { "id": "C012TEAMENG", "name": "team-eng", "is_channel": true, "is_private": false, "is_member": true },
      { "id": "C034TEAMOPS", "name": "team-ops", "is_channel": true, "is_private": false, "is_member": true }
    ],
    "response_metadata": { "next_cursor": "" }
  },
  "meta": {
    "profile_name": "team-eng",
    "team_id": "T012EXAMPLE",
    "user_id": "U012BOTUSER",
    "method": "conversations.list",
    "command": "conv list"
  }
}

2. Post the message

Write commands are explicit wrapper commands. If you want a dry read-only shell, set SLACKCLI_ALLOW_WRITE=false; posting requires writes to be allowed.

$ SLACKCLI_ALLOW_WRITE=true slack --profile team-eng msg post C012TEAMENG "Deploy window starts at 15:00 UTC. I'll post notes in this thread."
{
  "response": {
    "ok": true,
    "channel": "C012TEAMENG",

      "ts": "1720000000.000100"
    }
  },

    "user_id": "U012BOTUSER",

  }
}

3. Search for the update

The search command wraps message search and can page through results with --all when needed. This small query asks for one hit.

$ slack --profile team-eng search "\"Deploy window\" in:team-eng" --count 1
{
  "response": {
    "ok": true,
    "messages": {

          "user": "U012BOTUSER",
